═══════════════════════════════════════════════════════════
   🐛 TROUBLESHOOTING
═══════════════════════════════════════════════════════════

Arduino shows TIMEOUT:
   • Check SIM card has data/load
   • Verify APN is correct for your carrier
   • Check GPRS connection: AT+SAPBR=2,1

GPS shows "V" status:
   • Move GPS module to window or outside
   • Wait 1-5 minutes for first fix
   • Check GPS antenna is connected

API returns error:
   • Check JSON format in Serial Monitor
   • Verify SERVER_URL in code
   • Test with curl first

Map not updating:
   • Check if Arduino is sending (Serial Monitor)
   • Refresh browser (Ctrl+F5)
   • Check latest data: curl http://54.254.135.119/api/location/latest
