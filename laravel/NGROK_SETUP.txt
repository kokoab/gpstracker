===============================================
NGROK SETUP - Make Localhost Public
===============================================

Since you want to use localhost and the SIM900A needs
a public URL, ngrok is the PERFECT solution!

===============================================
WHAT IS NGROK?
===============================================

Ngrok creates a secure tunnel from the internet to
your localhost. It gives you a public URL that anyone
(including your SIM900A via GPRS) can access.

Internet → https://abc123.ngrok.io → localhost:8000

===============================================
STEP-BY-STEP SETUP
===============================================

1. INSTALL NGROK:

   Option A - Using snap (easiest):
   sudo snap install ngrok

   Option B - Manual download:
   wget https://bin.equinox.io/c/bNyj1mQVY4c/ngrok-v3-stable-linux-amd64.tgz
   tar -xvzf ngrok-v3-stable-linux-amd64.tgz
   sudo mv ngrok /usr/local/bin/

   Option C - Visit:
   https://ngrok.com/download

2. SIGN UP (FREE):

   Visit: https://dashboard.ngrok.com/signup

   After signup, get your auth token and run:
   ngrok config add-authtoken YOUR_TOKEN_HERE

3. START NGROK TUNNEL:

   Open a NEW terminal and run:
   ngrok http 8000

   Keep this terminal running!

4. COPY THE PUBLIC URL:

   You'll see output like:

   Forwarding   https://abc123.ngrok.io -> http://localhost:8000

   Copy: https://abc123.ngrok.io

5. UPDATE ARDUINO CODE:

   Edit: arduino_gps_tracker.ino
   Line 23:

   const char* SERVER_URL = "https://abc123.ngrok.io";

   (Use YOUR ngrok URL, not abc123.ngrok.io!)

6. UPLOAD TO ARDUINO

7. DONE! 🎉

===============================================
NGROK TERMINAL OUTPUT EXAMPLE
===============================================

ngrok                                                    (Ctrl+C to quit)

Session Status                online
Account                       your@email.com (Plan: Free)

Latency                       -

                              0       0       0.00    0.00    0.00    0.00

===============================================
USING NGROK
===============================================

✓ Leave ngrok running in a terminal
✓ Your Laravel app is now accessible from anywhere
✓ SIM900A can reach it via GPRS
✓ You can still use http://localhost:8000 locally

To monitor requests:
  Visit: http://127.0.0.1:4040
  See all HTTP requests in real-time!

===============================================
IMPORTANT NOTES
===============================================

FREE PLAN:
  • URL changes each time you restart ngrok
  • 40 connections/minute limit
  • Session expires after 2 hours (reconnects automatically)

  For permanent URL: Upgrade to paid plan ($8/month)

SECURITY:
  • This is for testing/school projects
  • No authentication in our app
  • Don't expose sensitive data
  • For production, deploy to proper hosting

===============================================
ALTERNATIVE TO NGROK (If you prefer)
===============================================

Other tunnel services:

1. LocalTunnel:
   npm install -g localtunnel
   lt --port 8000

2. Cloudflare Tunnel (Argo):
   cloudflared tunnel --url http://localhost:8000

3. Serveo:
   ssh -R 80:localhost:8000 serveo.net

All work similarly - give you a public URL!

===============================================
TESTING WITH NGROK
===============================================

1. Start Laravel:
   docker-compose up -d

2. Start ngrok in another terminal:
   ngrok http 8000

3. Test from outside:
   curl https://YOUR-NGROK-URL.ngrok.io/api/location/latest

4. Update Arduino code with ngrok URL

5. Upload and test!

===============================================
MONITORING ARDUINO REQUESTS
===============================================

Once Arduino is sending data, you'll see in:

1. Ngrok Web Interface (http://127.0.0.1:4040):
   - POST /api/location
   - Status: 201 Created
   - Request body (JSON)
   - Response from Laravel

2. Laravel Logs:
   docker-compose logs -f app

3. Arduino Serial Monitor:
   - HTTP responses from server
   - +HTTPACTION: 1,201
   - Success messages

===============================================
QUICK REFERENCE
===============================================

# Start everything:
cd /home/angelo/documents/gps/laravel
docker-compose up -d              # Terminal 1: Laravel
ngrok http 8000                   # Terminal 2: Ngrok

# Check system:
curl http://localhost:8000                          # Local access
curl https://YOUR-URL.ngrok.io                     # Public access
curl https://YOUR-URL.ngrok.io/api/location/latest # Test API

# Monitor:
http://127.0.0.1:4040                              # Ngrok dashboard
docker-compose logs -f app                         # Laravel logs
