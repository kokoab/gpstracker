===============================================
HARDWARE SETUP (SIM900A)
===============================================

POWER REQUIREMENTS:
- SIM900A needs EXTERNAL 5V/2A power supply
- Arduino 5V pin is NOT enough (causes brownouts)
- Use dedicated power adapter or buck converter

CONNECTIONS:
SIM900A:
  RX  → Arduino Pin 7
  TX  → Arduino Pin 8
  GND → Arduino GND + Power Supply GND (common ground!)
  VCC → External 5V/2A

NEO-6M GPS:
  RX  → Arduino Pin 4
  TX  → Arduino Pin 5
  GND → Arduino GND
  VCC → Arduino 5V

===============================================
SIM900A AT COMMAND SEQUENCE
===============================================

The Arduino code automatically executes:

1. AT+SAPBR=3,1,"CONTYPE","GPRS"     // Set connection type
2. AT+SAPBR=3,1,"APN","your_apn"     // Set APN
3. AT+SAPBR=1,1                       // Open GPRS connection
4. AT+HTTPINIT                        // Initialize HTTP
5. AT+HTTPPARA="URL","server_url"    // Set URL
6. AT+HTTPPARA="CONTENT","application/json"
7. AT+HTTPDATA=length,10000          // Prepare to send data
8. [JSON payload]                     // Send GPS data
9. AT+HTTPACTION=1                    // Execute POST (1=POST)
10. AT+HTTPREAD                       // Read response
11. AT+HTTPTERM                       // Terminate HTTP

===============================================
TROUBLESHOOTING
===============================================

PROBLEM: SIM900A not connecting to GPRS
SOLUTION:
  - Check SIM card has data plan
  - Verify APN settings
  - Check signal strength (AT+CSQ should return >10)
  - Ensure external power supply is adequate (2A minimum)

PROBLEM: GPS not getting fix
SOLUTION:
  - Move to open area with clear sky view
  - Wait 30-60 seconds for cold start
  - Check antenna connection
  - Verify NEO-6M power (LED should blink)

PROBLEM: HTTP POST fails
SOLUTION:
  - Verify server URL is accessible from internet
  - Check firewall allows port 8000
  - Use public IP, not localhost
  - Test with curl from another device

PROBLEM: Map not showing marker
SOLUTION:
  - Check browser console for errors (F12)
  - Verify API returns data: curl http://localhost:8000/api/location/latest
  - Check database has records: docker-compose exec app php artisan tinker
    >>> App\Models\Location::count()

PROBLEM: Marker not updating
SOLUTION:
  - Check browser console for fetch errors
  - Verify auto-refresh is working (check Network tab)
  - Ensure GPS is sending new data (check Serial Monitor)

===============================================
DATABASE SCHEMA
===============================================

Table: locations
  - id (bigint, primary key)
  - device_id (varchar, indexed)
  - latitude (decimal 10,7)
  - longitude (decimal 10,7)
  - created_at (timestamp, indexed)
  - updated_at (timestamp)

Query latest location:
  SELECT * FROM locations ORDER BY created_at DESC LIMIT 1;
