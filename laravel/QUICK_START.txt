===============================================
GPS TRACKER - QUICK START
===============================================

SYSTEM STATUS: ✓ READY

Web Interface: http://localhost:8000
API Endpoint:  http://localhost:8000/api/location

===============================================
ARDUINO SETUP (REQUIRED)
===============================================

1. Open: arduino_gps_tracker.ino

2. Change line 18 - YOUR SERVER IP:
   const char* SERVER_URL = "http://192.168.1.XXX:8000";
   
   Get your IP: ip addr show | grep "inet " | grep -v 127.0.0.1

3. Change line 19 - YOUR APN:
   Globe: const char* APN = "internet.globe.com.ph";
   Smart: const char* APN = "smartlte";

4. Upload to Arduino Uno

5. Open Serial Monitor (9600 baud)

===============================================
HARDWARE CONNECTIONS
===============================================

SIM900A (NEEDS EXTERNAL 5V/2A POWER!):
  RX  → Pin 7
  TX  → Pin 8
  GND → Arduino GND + Power GND (common ground)
  VCC → External 5V/2A (NOT Arduino 5V!)

NEO-6M GPS:
  RX  → Pin 4
  TX  → Pin 5
  GND → GND
  VCC → 5V

===============================================
DOCKER COMMANDS
===============================================

Start:    docker-compose up -d
Stop:     docker-compose down
Logs:     docker-compose logs -f app
Restart:  docker-compose restart app

===============================================
TEST THE SYSTEM
===============================================

1. Send test GPS data:
   curl -X POST http://localhost:8000/api/location \
     -H "Content-Type: application/json" \
     -d '{"device_id":"BUS001","latitude":14.5995,"longitude":120.9842}'

2. View on map:
   Open http://localhost:8000 in browser

3. Check API:
   curl http://localhost:8000/api/location/latest

===============================================
WHAT HAPPENS
===============================================

1. GPS gets coordinates → Arduino
2. Arduino formats JSON → SIM900A
3. SIM900A sends HTTP POST → Laravel API
4. Laravel stores in MySQL database
5. Map fetches latest location every 5 seconds
6. Marker updates in real-time

===============================================
TROUBLESHOOTING
===============================================

GPS not fixed?
  → Go outside, wait 30-60 seconds

SIM900A not sending?
  → Check external power (2A minimum)
  → Verify APN settings
  → Check SIM has data plan

Map not showing?
  → Open browser console (F12)
  → Check: curl http://localhost:8000/api/location/latest

===============================================
MONITORING
===============================================

Arduino Serial Monitor: 9600 baud
  Shows: GPS fix status, HTTP responses

Laravel Logs:
  docker-compose logs -f app

Database:
  docker-compose exec app php artisan tinker
  >>> App\Models\Location::latest()->first()
